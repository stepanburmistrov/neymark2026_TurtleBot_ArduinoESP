# Интенсив по мобильной робототехнике — Неймарк 2026

![Робот, собранный на интенсиве](images/robot_day_01.png)

В этом репозитории собраны программы, инструкции и дополнительные материалы интенсива по мобильной робототехнике.

Робот собирается поэтапно: после подключения каждого нового компонента загружается отдельная проверочная программа. Только когда все узлы работают независимо, они объединяются в общие алгоритмы.

```text
    ├── 04_ir_raw_check/
    ├── 05_ir_distance_check/
    ├── 06_servo_check/
    ├── 07_start_button_check/
    ├── 08_line_following/
    ├── 09_doorway_search/
    └── 10_kegelring/
```

Каждый Arduino-скетч находится в отдельной папке с тем же названием, что и файл `.ino`. Поэтому любую программу можно открыть в Arduino IDE непосредственно из своей папки.

## Как работать с материалами

1. Откройте папку нужного дня.
2. Прочитайте порядок подключения и проверки компонентов.
3. Загружайте программы строго по порядку.
4. Не переходите к следующему этапу, пока текущая проверка не даёт ожидаемый результат.
5. Перед изменением проводки отключайте питание робота.
