# ArUco `DICT_4X4_50`, ID 0–9

Файлы подготовлены для печати и учебных экспериментов.

- `marker_0.png` … `marker_9.png` — отдельные маркеры с белым полем;
- `aruco_sheet_ids_0_9_A4.png` — общий лист формата A4 при печати без масштабирования.

Для робота в примере `16_click_to_drive.py` используется **ID 4**. Верхняя сторона изображения маркера должна быть направлена вперёд по корпусу робота.

Рекомендации:

- печатать без сглаживания и без обрезки белой рамки;
- наклеивать на плоское жёсткое основание;
- не закрывать чёрную рамку крепежом;
- избегать бликов и сильного изгиба бумаги.
